# Project 9 Dashboard Contract

The self-contained offline HTML dashboard consumes frozen release data only. It has exactly these tabs and stranger-facing questions:

| Tab | Question |
|---|---|
| The Story | Why care before knowing anomaly-detection terminology? |
| See the Mechanism | What changes between raw and point-adjusted evaluation? |
| The Experiment | What was held constant, varied, and measured? |
| Results | What did the validated experiment show? |
| 45s Video | Can the study be understood quickly without prior context? |
| Why It Matters | What broader lesson and limits follow? |

The page explains anomaly detection, anomaly events, raw pointwise scoring, and point adjustment before introducing F1, Monte Carlo, or Kim et al. It may not contain hand-entered public-result values.
