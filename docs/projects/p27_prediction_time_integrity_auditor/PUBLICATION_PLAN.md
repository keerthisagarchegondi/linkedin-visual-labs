# Publication Plan

## Immediate artifact

Versioned source, tests, manuscript, figures, benchmark tables, citation
metadata, and reproducibility evidence.

## Later, only after explicit approval

1. GitHub versioned release.
2. Zenodo archive and actual issued DOI.
3. Factual-review preprint preparation.
4. Potential TMLR evaluation after expansion.
5. Potential JOSS evaluation after sustained software maturity.

## Prohibited claims before evidence exists

- invented DOI;
- peer-reviewed status;
- acceptance;
- reviewer identity;
- citation count;
- download count;
- arXiv identifier;
- O-1 eligibility.

The MVP is a validated technical case study and software prototype.
