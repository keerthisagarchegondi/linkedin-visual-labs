# Project 8 — Sampled Recommendation Metrics

Research question:

> Can sampled recommendation metrics select the wrong model?

This project independently implements a selected toy example from
Krichene and Rendle's work on sampled recommender-evaluation metrics.

## Step 1 status

Step 1 establishes:

- typed configuration;
- verified source inputs;
- stable experiment/evidence identifiers;
- machine-readable schema vocabulary;
- input validation;
- CLI wiring;
- reproducibility documentation.

No Project 8 metric results are produced in Step 1.

## Scope

The project does not train recommendation models and does not use real
customer data. Profiles A, B, and C are hypothetical ranking profiles
from the published toy example.
