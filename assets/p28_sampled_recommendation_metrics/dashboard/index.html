Methods & evidence

What the study starts from, what is computed, and what may safely be claimed.

Evidence-first view
Evaluation protocol
Input
Fixed source-reported A/B/C relevant-item rank profiles.
Catalog size
10,000 candidate items.
Cases/profile
5 held-out test cases.
Reference sampling
Keep the relevant item + sample 99 negatives.
Sampling rule
Uniform negative sampling with replacement.
Sampled rank
R = 1 + X, where X ~ Binomial(m,p), p=(r−1)/(N−1).
AP
1 / rank for one relevant item.
NDCG
1 / log2(rank + 1), untruncated.
Recall@10
Indicator(rank ≤ 10).
AUC
(N − rank)/(N − 1); negative control.
Project 8 starts after model scoring/ranking. Raw customer features and model training are outside this study.
Study limitation
This is a controlled toy example with five cases per profile and one relevant item per case. It demonstrates that a model-selection reversal can occur; it does not estimate how frequently or how strongly the effect occurs in production recommender systems.
Supported public claims
Claims deliberately rejected / bounded
Provenance
Attribution: independently reproduces and extends a toy ranking example attributed to Krichene & Rendle. A/B/C rank profiles are source-reported; analytical derivations, sample-size sweep, Monte Carlo validation, independent recomputation, figures and dashboard are independently implemented.
