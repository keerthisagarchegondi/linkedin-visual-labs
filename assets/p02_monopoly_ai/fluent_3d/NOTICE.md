# Project 3 — Strategy Piece Artwork Notice

## External source artwork

The rendered strategy-piece source artwork used by Project 3 is
derived from Microsoft Fluent Emoji.

Source project:
- Microsoft Fluent Emoji
- 3D rendered artwork style

License:
- MIT License
- Copyright (c) Microsoft Corporation

Project 3 performs deterministic transformations of the selected
source PNG artwork using Pillow and NumPy. These transformations
include alpha cropping, scale normalization, metallic-silver tonal
mapping, contrast/sharpness adjustment, grounding shadow, and a
small strategy-identity accent.

## Project 3 strategy mappings

- Collector
  - rendered racing/sports-car visual
  - Project 3 output: silver_sports_coupe

- Specialist
  - rendered sailboat visual
  - Project 3 output: silver_yacht

- Cash Protector
  - rendered lock/protection visual
  - Project 3 output: silver_armored_vault

- Aggressive Builder
  - rendered tractor visual
  - Project 3 output: silver_construction_loader

The Project 3 output filenames describe the semantic game-piece
roles used by the visualization; they do not claim that the source
artwork is a literal 3D mesh of those named objects.

## Board-game artwork

Project 3 uses its own board visualization, property-space artwork,
cash, cards, ownership markers, development markers, HUD elements,
and statistical graphics.

No official Monopoly or Hasbro logo, board artwork, cards, fonts,
or playing-token artwork is used.

The Microsoft Fluent Emoji license text is retained alongside this
notice in MICROSOFT_FLUENT_EMOJI_LICENSE.txt.
